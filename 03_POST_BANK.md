# 03 — POST BANK

Every post lives here, in publication order. One block per post, in the exact
format defined in `_SHARED/post-anatomy.md`. The copy pack is the render-ready
version. The table is the same post in one view.

Workflow:

```bash
node tools/new-post.js "Working Title" --pillar "Pillar" --interrupt 7 --clips 6
node tools/validate-posts.js 03_POST_BANK.md
```

Never split a post across files. The post is the single production record.

**`Length:` is the content runtime only.** Every published post adds the Saint
Naomis intro (0.8 s) and outro (2.4 s) on top. See `_SHARED/intro-outro.md`.

**Published copy rules:** no em dashes, no emojis, no exclamation marks. No
exam, admission or scholarship promise. Every face carries `Illustrative image.
Not a real student.` Every composite carries the composite line.
