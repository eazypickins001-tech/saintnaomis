# 05 — PROOF TRACKER

> The channel's own analytics are the case study. Log every post; the numbers
> decide what the standing instruction becomes.

---

## 1. Metrics that matter

| Metric | Why it matters | Target |
|---|---|---|
| **3-second hold** | The interrupt worked or it didn't | 70-80% |
| **Views 24 h** | Launch strength | first 10 posts: 2,000 |
| **Views 7 d** | Distribution tail | first 10 posts: 6,000 |
| **Avg watch time** | The payoff held | ≥ 50% of runtime |
| **Follows** | The identity landed | 1 per 1,000 views |
| **Shares** | "Send this to someone" | highest-value signal |
| **Comments** | The open loop invited reply | ≥ 3 real threads |
| **Saves** | Utility or rewatch value | 1 per 500 views |
| **Profile visits** | The file label created curiosity | 2 per 1,000 views |

Optimise `3-second hold` and `shares` first. Views follow.

## 4. Learning log

Every non-obvious result gets one line. This becomes the channel's private
playbook.

| Date | Observation | Evidence | Action taken |
|---|---|---|---|
| | | | |
| | | | |

Examples of the kind of entry that matters:

- "Faces in the first frame underperformed against objects and backs by 18%. The
  safeguarding rule is also a performance rule here."
- "Posts with a named exam in the overlay held 9 points better. Test Myth may
  deserve more than one slot a week."
- "The 48-second story format underperformed on TikTok but overperformed on
  Facebook. Keep stories for Facebook and YouTube."
- "A comment asking 'is this real' means the AI-face line was too small. Move it
  to the first comment."

---

## 5. Correction rule

If a published post carries a wrong figure, a wrong name, an unsourced claim or
an unconfirmed service:

1. Correct the caption within 24 hours.
2. Pin a comment that states the correction plainly.
3. Log it here with the date and the cause.
4. If the error came from a prompt or a template, fix the template, not only the
   post.

---

## 6. Promotion rule

A learning is promoted to the shared engine **only** when it is general, not
project-specific:

- Project-specific: stays here.
- General (a hook law, a category rule): propose it for
  `_SHARED/hook-architecture.md` in the template repo, then copy the updated
  `_SHARED/` into every project.
